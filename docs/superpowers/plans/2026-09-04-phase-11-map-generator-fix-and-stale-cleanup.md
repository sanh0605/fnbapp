## Task 1: extract-tables — handle DROP TABLE

**Files:** `scripts/system-map/extract-tables.ts`, `scripts/system-map/extract-tables.test.ts`.

- [ ] **Step 1: Failing test** — add a case: given sqlSources `["create table public.a (id text);", "create table public.b (id text);", "drop table public.a;"]`, `extractTables` returns only `b` (a is dropped). Also: a table dropped then re-created later stays. Run → FAIL on current code (returns both a and b).
- [ ] **Step 2: Implement** — process CREATE and DROP in source order (across the ordered sqlSources, and by position within each). CREATE adds/updates the table; `DROP TABLE (IF EXISTS)? (public.)?<name>` removes it. Add `const DROP = /drop table (?:if exists )?(?:public\.)?(\w+)/gi;`. Simplest correct approach: build an ordered list of events (create|drop, name, [file-index, position]) then fold. Preserve existing column/enum extraction for surviving tables.
- [ ] **Step 3:** Run test → PASS. Run full `npx vitest run scripts/system-map/` → green.
- [ ] **Step 4: Commit** — `git commit -m "fix(system-map): extract-tables honors DROP TABLE (drops 6 phantom tables)"`.

## Task 2: extract-rpc — match dollar-quote-tagged function bodies
